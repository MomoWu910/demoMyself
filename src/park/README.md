# Cloud Park · 雲朵樂園

首頁「遊樂場」→ `park.html` → 星光賭場門口互動 → 原有 `arcade.html`。

Three.js 第三人稱遊樂園。所有場景造型以程式幾何建立，沒有外部模型或貼圖下載；招牌使用 CanvasTexture。美術參考 hololive Dreams 官方園區的明亮玩具感，場景、角色與介面為本專案原創。

## 操作

- 桌機：WASD／方向鍵移動、滑鼠轉向、F 互動、空白鍵跳躍、M 地圖。按住 Alt 顯示游標，放開時嘗試恢復原先的 Pointer Lock；Esc 持續釋放滑鼠。首次點擊取得 Pointer Lock；不允許 Pointer Lock 的環境仍可拖曳轉向。滑鼠預設水平靈敏度為 0.0012 rad/px，約原版三分之一。
- 手機：左側虛擬搖桿、右側拖曳視角、右下互動鍵與獨立跳躍鍵。全螢幕按鈕在瀏覽器允許時要求橫向鎖定；直屏時使用橫向旋轉畫面，觸控 delta 同步轉換。
- 左上小地圖可打開全圖；目的地列表及地圖標記均支援快速旅行與鍵盤操作。
- 摩天輪／旋轉木馬有 25 秒搭乘視角，F 可提早離開；噴泉切換水色、茶屋領氣球，園內另有 5 顆可收集星星。
- 六張長椅可靠近按 F 坐下，再按 F 起身；空白鍵可直接起身跳躍。空中不能重複跳躍或啟動設施互動，搭乘中停用跳躍。

## 模組

- `world.ts`：地標、出生點、碰撞、星星與互動距離的共用資料。移動分步且逐軸滑牆。
- `scene.ts`：場景與角色、設施動畫、instanced 樹木、資源釋放。靜態場景陰影只生成一次，角色用接觸影；動態設施不更新投影。
- `craft.ts`：拱窗、曲面屋頂、金屬曲線扶手、分片木條座椅、花朵、磚面與靜態網格合併。細節按材質合併，移動車廂與木馬仍各自獨立。
- `input.ts`：鍵盤、Pointer Lock、拖曳鏡頭、多指觸控、直屏座標轉換、失焦清除。
- `map.ts`：SVG 小地圖與大地圖、方向指示、收集狀態、可操作目的地。
- `index.ts`：遊戲迴圈、鏡頭、互動、搭乘、旅行與導航。

`npm run check:park` 驗證所有旅行點及星星可從入口走到、旅行後可以互動、碰撞防穿牆、邊界、滑牆與旋轉輸入。

此頁目前使用繁體中文介面及英文設施名稱；既有頁面的中英文切換不受影響。手機橫向與 Pointer Lock 的實際支援依瀏覽器而異，需以真機補驗。

### 鋪面與碰撞

道路與長椅休息區使用 `PATHS`，矩形聯集拆成互不重疊的面，紋理依世界座標連續鋪設，避免路口 Z-fighting。小地圖共用道路與座椅位置。

玩家碰撞半徑為 0.4；圓形設施、桌面、樹幹與花盆使用圓形，建築、櫃台、圍欄與旋轉長椅使用定向矩形及最近點檢測。碰撞涵蓋步行高度的固定實體，花朵與高架雨棚不阻擋通行；跳躍仍沿用平面碰撞。長椅設於步道外側的鋪面休息區，朝向與起身位置共用座椅配置。

搭乘摩天輪時角色會縮放並固定在第一節車廂的地板中央；搭乘旋轉木馬時固定在第一匹木馬的鞍座。兩種設施都保留滑鼠或觸控環視，且只會在玩家按 F／互動鍵時下車。
